# This project is a Family Operating System that keeps families connected safely.
# It allows you to give close family access to seeing the growth of your child with an added layer of privacy.
# Social Media has become an unsafe place to share family moments and this solves the issue.
# Each family member will be given separate permissions authorized by the owner to carefully mitigate who gets access
# their child. This system is built for parents to better organize and family plan as well as keep babysitters and 
# grandparents in the loop with allergies and medications that the child needs. This SaaS is a Family Ecosystem that
# keeps everyone informed and will bring families closer.
