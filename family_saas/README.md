# family_saas

The premise of this project is to create a SaaS (Software as a Service) that allows
for an environment where families can effectively share the progress of their child with grandparents/friends. It will show their milestones as a baby, favorite foods, colors, shows, christmas/birthday lists, calendar schedule for doctor appointments, sports, etc. This platform will give parents the ability to efficiently plan their days together and send notifications. Widgets will be created that keeps the parents up to date with each child including their theme days at school and grades. Two-factor authentication will be used to ensure accounts are secured and every invite will need a code provided by primary account holder to gain access to an existing account.
